## 📝 Future Content Checklist

When adding new project pages or blog posts, follow this:

### 1. Page Title
- Keep under 60 characters
- Include main keyword near the start
- Make it attractive for clicks
- Example: "Restaurant Logo Design Dhaka | Shams Visuals"

### 2. Meta Description
- Keep 150-160 characters
- Include main keyword naturally
- Add a call-to-action
- Example: "Custom restaurant logo design in Dhaka by Ahmed Shams. Professional branding that attracts customers. See the project and get a quote today."

### 3. H1 Heading
- Only ONE H1 per page
- Include main keyword
- Make it compelling
- Example: "Restaurant Branding & Logo Design"

### 4. Subheadings (H2, H3)
- Use H2 for main sections
- Use H3 for subsections
- Include related keywords naturally

### 5. Image Alt Text
- Describe what's in the image
- Include relevant keywords
- Keep under 125 characters
- Format: "[description]-[location]-shams-visuals"
- Example: "restaurant-logo-design-dhaka-shams-visuals"

### 6. Image File Names
- Use lowercase with hyphens
- Be descriptive
- Example: "restaurant-branding-project-dhaka.jpg"

### 7. Internal Links
- Link to related projects
- Link to relevant service packages
- Link to contact/WhatsApp
- Use descriptive anchor text (not "click here")

### 8. Content Structure
- Short paragraphs (2-3 sentences)
- Bullet points for features/benefits
- Clear headings to break up text
- Easy to scan on mobile
